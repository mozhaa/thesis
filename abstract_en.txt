Currently, various applied fields require storing and processing large volumes of data. Lossless compression algorithms help reduce storage space, but existing software solutions do not fully offer a convenient and efficient interface for random access and data modification. This work is devoted to the development and implementation of a number of core components of the Compio library, designed for transparent data compression, which provides an interface similar to standard C language I/O but with support for on‑the‑fly compression. A key feature of the library is efficient random access (both for reading and writing, as well as insertion and deletion) to compressed data without requiring full file decompression. The author implemented an approach in which data is split into variable‑sized blocks, each compressed individually, and indexed by a B‑tree that supports bulk operations (including key shifts based on deferred updates). A mechanism of block size bounds is proposed to prevent performance degradation due to internal fragmentation during prolonged modifications. A two‑level cache for decompressed blocks based on the 2Q‑LRU algorithm is implemented, along with caching of B‑tree nodes. Performance tests have shown that, depending on the usage scenario and library configuration, random read speeds on modern desktop/server hardware range from 600 MB/s to 18 GB/s, and random write speeds range from 80 MB/s to 5 GB/s. Comparative tests with tools designed only for random reading (Zran, Seekable Zstd) demonstrate that Compio achieves comparable or higher read speeds while simultaneously providing efficient writing, insertion, and deletion. It is also shown that the storage overhead (increase in file size compared to single‑stream compression) does not exceed 9%, meaning the library is suitable for practical applications.
